## Finding — the coarse "EQUIVALENT" label conflated E and R

The 5 manifest survivors were all labelled "EQUIVALENT" in `allowed-survivors.txt`, but each reason is
"redundant with a downstream Bind->Validate check that also rejects", and `mutation_kill_test.go`
exists precisely to kill those downstream Validate-layer mutants. Under the detector-power taxonomy
(spec §2) that is **R (redundantly-pinned)**, not E. Proof is the sweep itself: the subsuming lines
(manifest.go:209/212/218/221 and the required-field loop) are NOT among the 5 survivors — their
mutants were killed in the same sweep. Reclassified to R with the specific pinning test named per
survivor (TestBindRejectsDuplicateAndInvalidInputs, TestValidateRejectsEachUnsafeSubBranch,
TestValidateRejectsBindingOrderAndDigest, TestParseRejectsShapeAndCanonicality).

`LESSON: class=coarse-survivor-label-conflates-e-and-r response=scripts/detector-power.sh` — a single
"equivalent-outcome" allowlist label hides the E-vs-R distinction that regeneration-trust turns on;
the compiled response is the gate's E/R/U classification + the register/record class cross-check.

## Two bugs the hardened self-test / real run caught

- The DP-5 "bad summary" control first routed `jq --arg` through a helper that used only `$1`, so the
  record was rejected for invalid-JSON rather than for DP-5 — a non-load-bearing control. Fixed; then
  hardened every control to assert the intended DP tag in the failure message.
  `LESSON: class=positive-control-right-reason response=scripts/tests/detector-power.test.sh` — a
  reject-control must assert WHY it was rejected, or it can pass by tripping an unrelated check.
- The `--refresh` path treated `scripts/mutants.sh`'s exit 1 as a failure — but mutants EXITS 1
  whenever survivors exist (the normal case for every detector-power package), so refresh was broken
  for exactly the packages it serves. Fixed to accept exit <=1 (1=survivors, 2=tool error) and
  validate the output shape.
  `LESSON: class=sweep-exit-is-survivors-not-failure response=scripts/detector-power.sh` — a
  non-zero sweep exit encodes "survivors present", not "command failed".
