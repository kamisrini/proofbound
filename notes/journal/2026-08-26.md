and sessions from the projection views over the UTC event window `[now-7d, now)`, carries
the originating event ID on every data entry, and retains unreachable commits marked
`[superseded]`. Git reachability uses a lightweight `rev-list --all` query and includes a
detached `HEAD` when it resolves to a commit.

joins, added explicit fail-closed errors, and added a PostgreSQL regression test. The
remediation is `327219c`; the independent verifier re-reviewed it and returned
`ACCEPTABLE`, committed verbatim at
`docs/verification/verdicts/task8-current-round1.md`.

and bare `make check`. Mutation calibration remains a disclosed LOW limitation: the
integration baseline exceeded the harness's 30-second ceiling after cache initialization,
while the untagged sweep cannot prove database logic. No mutation count was claimed.

LESSON[claim-outruns-evidence]: A passing integration test and a mutation harness run are
