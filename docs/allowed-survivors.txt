# Mutation survivors that need no test, with the reason each one does not.
#
# Format: <file>:<line>#<ord>\t<op>\t<desc>  # why
# Copy the SURVIVOR line from `bash scripts/mutants.sh <pkg>` verbatim, then two spaces and a reason.
#
# A survivor is a line no test defends: the mutation applied, the code compiled, the suite passed.
# The only honest reasons to declare one instead of writing a test:
#   - EQUIVALENT MUTANT: the mutation cannot change observable behaviour (e.g. a log string).
#   - UNREACHABLE BY CONSTRUCTION: the branch cannot be entered, and something else proves that.
#   - NO SEMANTIC CONTENT: a literal that carries no meaning to any caller.
# "We will get to it" is not a reason — that is the defect this harness exists to stop shipping.
#
# DETECTOR-POWER CLASS ANNOTATION (P7 #2b, CI-p7-detector-power-1a2b3c). A survivor that is covered by
# a per-package detector-power record (docs/verification/detector-power/<pkg>.json) carries a finer
# E/R/U class in-line as `{dp:class=E|R|U}`, which scripts/detector-power.sh CROSS-CHECKS against the
# record (a mismatch fails closed — Law 2 drift guard). The old coarse "EQUIVALENT" label conflated
# two of these: E (semantically identical, un-killable by any test) and R (REDUNDANTLY-PINNED — a
# second TESTED line also rejects, so the mutant survives here but the behavior is pinned there). The
# pinning test/line and the subsumption argument for an R live ONCE, in the record's `pins`+
# `justification` (Law 2: linked from here by the key + the class=R marker, never copied).
#
# The KEY INCLUDES THE ORDINAL (#n) because file+line+op+desc collide — one line with two `||`
# operators produces two identical descriptions. An allowlist that cannot tell two sites apart
# licenses the wrong one.
#
# Line numbers and ordinals MOVE. Re-run the sweep after any edit to the package and refresh these
# entries; a stale entry silently licenses a DIFFERENT site than the one it was written for.
#
