# The Intent gate checks what the kernel binds, not what the message mentions (DEF-INTENT-TRAILER-BLOCK-001)

**ACCEPTED by the owner 2026-11-16** (recorded by the agent as scribe; the owner is the acceptor,
Law 9). Implements [[BR-gate-integrity-4b2e08]] obligation **O-1**: the acceptance gate must be a
trustworthy witness.

Resolves `DEF-INTENT-TRAILER-BLOCK-001`. The kernel's git adapter (`intentTrailers` in
`kernel/internal/connector/git/gitcmd/gitcmd.go`) binds an `Intent:` claim only from the final
trailer block (git-connector INV-28). The shell gate `scripts/intent-delivery-applicability.sh`
grepped the whole message for `^Intent:`. By the kernel's grammar 17 of 30 governed-history commits
carry no bindable trailer — 14 of them touched governed paths, so the gate demanded a trailer, was
satisfied by a body line, and the Trust Record recorded no claim. The harness verified presence,
not binding.
