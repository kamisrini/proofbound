# A NEEDS_WORK review blocks the commit

**ACCEPTED by the owner 2026-11-24** ("go", after the live agent run). Implements
[[BR-change-area-p59cyd]] O-2 and [[BR-tests-can-fail-k2h06j]] O-5: a reviewer's reject makes the verdict
NEEDS_WORK, and a NEEDS_WORK verdict now blocks the readiness gate and the warranty. Design:
[needs-work-blocks-spec.md](../../../../plans/needs-work-blocks-spec.md).

## Allowed scope
`kernel/internal/projections` (the verdict status column, its in-place migration, the intent report),
`kernel/internal/gates` (the readiness rule and its reason), `kernel/internal/warranty` (`CheckRule`),
`kernel/internal/cli` (`report drift`, and the agent answer, which must not say done for a BLOCKED commit),
their tests and SPEC rows, the sdd end-to-end test, and docs.

## Explicit exclusions
No new event kind, no change to verdict files or to sealing, no new dependency.

## Acceptance boundary
`make check` green, a mutation check with calibration controls, one non-author code review, and the live
agent run's commit reading NOT WARRANTED with no warranty issued.
