authorization [[VD-agent-standing-authorization-5ouz7q]], 2026-10-31) for the bounded non-runtime
slice `P7-NONRUNTIME-BEHAVIOR-LOCK-1`, materializing the behavior-lock planning profile accepted in

Acceptance requires this exact scope and native self-digest, synthetic and committed-byte tests, a
calibrated package mutation sweep with every survivor declared, an independent non-author review of
the exact implementation revision and packet, and the owner-listed repository checks. The lock is a
non-runtime authored artifact and establishes no runtime acceptance.
