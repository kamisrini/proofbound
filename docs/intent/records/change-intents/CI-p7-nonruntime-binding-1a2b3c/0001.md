# P7-NONRUNTIME-BINDING-1 authorization

This accepted change intent records the owner’s authorization for the next bounded non-runtime
slice: deterministic binding of caller-supplied source and module bytes into the accepted
projector/build manifest contract.

## Allowed scope

- Add a pure binder that computes source-file, module `.mod`, and module `.zip` SHA-256 identities
  from bytes supplied by the caller.
- Produce the existing canonical manifest type with deterministic ordering and exact revision,
  toolchain-declaration, module, and build-setting validation.
- Add synthetic tests for byte identity, ordering, duplicate rejection, and invalid input.

## Explicit exclusions

This intent authorizes no network fetch, external artifact retrieval, toolchain or binary build,
executable validation, runtime fixture, launched process, PostgreSQL execution or approval,
`DEF-P7-001` activation or resolution, L12/L17 result, behavior-lock acceptance, clean-clone proof,
or runtime verdict. The binder must not read ambient caches, execute supplied bytes, or mutate the
ledger or a writable projection.

## Acceptance boundary

Acceptance requires exact-revision binding, deterministic byte hashing and ordering, independent
non-author review of the exact implementation commit and review packet, and the listed repository
checks. This intent does not expand or revise the accepted `P7-NONRUNTIME-MANIFEST-1` contract.
