# Staged-aware freshness for the git-log-pinned generated artifacts (DEF-ROUTE-MATRIX-PRECOMMIT)

**ACCEPTED under standing authorization** ([[VD-agent-standing-authorization-5ouz7q]]; owner is the
non-author acceptor, Law 9). Implements [[BR-gate-integrity-4b2e08]] obligation **O-1**: the
acceptance gate must be a trustworthy witness — including pre-commit.

Resolves `DEF-ROUTE-MATRIX-PRECOMMIT`. Three `@generated` artifacts pin a `code`/`input` commit
derived from `git log -1 -- <paths>`, which cannot see uncommitted work: a PRE-commit `make check`
false-greens while the pin goes stale the instant those paths are committed (this pushed a red gate
at `057bc07`). Each affected `--check` now fails closed when its pinned paths have pending
(staged/unstaged/untracked) changes, so the only route to a green pin is: commit the change, then
`--write` the pin, then commit it.

## Allowed scope
- `scripts/p6-route-matrix.sh`: pin `kernel/internal/{projections,cli,twin,gates}`; guard via
  `P6_ROUTE_PENDING_OVERRIDE` seam.
- `scripts/p6-task2-close.sh`: pin `kernel/internal/connector`, `kernel/internal/cli/cli.go`,
  `scripts/delivery-enforce.sh`, `scripts/tests/delivery-enforce.test.sh`; seam `P6_TASK2_PENDING_OVERRIDE`.
- `scripts/tests/{p6-route-matrix,p6-task2-close}.test.sh`: a positive control per guard
  (pending → fail) and a neutral control (clean → pass), driven by the seams.

## Explicit exclusions
- No change to the pinned content, the `--write` output, gate counts, `docs/gates.md`, or kernel code.
- **`scripts/p6-census.sh` is deliberately NOT guarded here.** Its `input_commit` pin also gates the
  C6 census horizon (`p6-census.sh:244` enumerates `f426ca8..input_commit`), so committing any change
  to it advances that horizon and forces classifying every intervening intent-commit — a
  disproportionate side effect. The same staged-aware guard applies to it in a separate, scoped
  change; `DEF-ROUTE-MATRIX-PRECOMMIT`'s proven incident (the route matrix) and the clean peer
  (`p6-task2-close`) are covered here.

## Acceptance boundary
Each self-test proves its guard fires on a pending pinned-path change and passes when clean; `make
check` green and deterministic. Governed commit lands with an `Intent: CI-staged-pin-guard-7b3c9d`
trailer and `Authorized-By: Srinivas Kamisetty`.
