This accepted change intent records the owner’s authorization for the bounded non-runtime slice
`P7-NONRUNTIME-SOURCE-TOOLCHAIN-INVENTORY-1`.

## Allowed scope

- Define a machine-readable source/toolchain evidence inventory for every projector-manifest field.
- Map each field to an exact safe relative committed evidence path or an explicit `UNVERIFIED`
  state.
- Validate exact field coverage, canonical ordering, matching evidence revisions, and the
  inventory’s digest binding to a caller-supplied canonical manifest.
- Add synthetic validation for missing, extra, duplicate, stale-revision, and digest-mismatch

## Explicit exclusions

This intent authorizes no runtime fixture or execution, network fetch, external artifact retrieval,
binary build or validation, PostgreSQL execution or approval, `DEF-P7-001` activation, L12/L17,
behavior-lock acceptance, clean-clone proof, runtime verdict, provider, event kind, writable truth,
or runtime behavior. The inventory must not read evidence paths, resolve Git trees, retrieve
toolchains or modules, execute bytes, or approve the pinned PostgreSQL JAR.

## Acceptance boundary

Acceptance requires the exact scope and native self-digest, synthetic tests, independent non-author
review of the exact implementation commit and review packet, and the repository checks listed in
the owner authorization. This intent does not establish complete projector/build evidence or
runtime acceptance.
