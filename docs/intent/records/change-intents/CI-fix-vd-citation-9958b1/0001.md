# Accept date-suffixed VD decision citations in the commit projection

**ACCEPTED under standing authorization** ([[VD-agent-standing-authorization-5ouz7q]]; owner is the
non-author acceptor, Law 9). Implements [[BR-self-hosting-correctness-4607a3]] obligation **O-1**.
Governed commits land with an `Intent: CI-fix-vd-citation-9958b1` trailer and
`Authorized-By: Srinivas Kamisetty`.

## Allowed scope
- `kernel/internal/projections/projections.go`: broaden `decisionPattern` to accept a terminal
  `YYYY-MM-DD` date suffix in addition to the existing `[a-z0-9]{6}` token, so the
  `/proofbound-decide` phase-decision form (e.g. `VD-p5-intent-provenance-2026-09-10`) validates
  rather than failing the projection apply closed.
- `kernel/internal/projections/citation_test.go` (new, NOT `-tags integration`): a regression guard
  that runs under `make check`, asserting both suffix forms are accepted and malformed citations are
  still rejected (P-INV-7).
- `kernel/internal/projections/SPEC.md`: a §3 note recording the accepted `cited_decisions` citation
  forms.

## Explicit exclusions
- No change to the ledger, event kinds, store, or any other projection validator (the `BD`/`BR`/`CI`
  intent-ref ID patterns remain 6-char-token-only, which is correct — intent records never use a date
  suffix).
- No change to what counts as malformed beyond admitting the date form; P-INV-7 fail-closed semantics
  are preserved.
- No new invariant ID (the rule is covered by the existing P-INV-7).

## Acceptance boundary
Acceptance requires this exact scope; the new regression test green under `make check` (no integration
tag); `make check` green and deterministic; a live `proofbound sync git` + `report week` against this
repo succeeds (verified: `report week` renders 85 commits incl. date-suffixed citations, exit 0); and
an independent non-author package verdict of `internal/projections` on the frozen implementation
revision, with a calibrated mutation sweep (Law 9 / package-acceptance bar). The owner remains the
final acceptor.
