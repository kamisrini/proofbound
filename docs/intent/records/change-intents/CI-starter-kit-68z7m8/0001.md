# R2 starter kit and reviewer workflow

**ACCEPTED by the owner 2026-11-19** ("lets do it as part of r2, go ahead"; recorded by the agent as
scribe). Makes the readiness gate ([`BR-sdd-warranty-i9miv7`](../../requirements/BR-sdd-warranty-i9miv7/0003.md)
O-8) usable on a one-person OpenSpec project: without it, nothing produces the verdicts and reviews a
PASS needs. Contract: [`docs/plans/R2-starter-kit-spec.md`](../../../../plans/R2-starter-kit-spec.md).

## Allowed scope
- `proofbound init openspec [--owner <name>]` and `proofbound review {draft <commit>|seal <dir>}`
  in `kernel/internal/cli` (CLI-INV-18..20), with embedded templates in `kernel/internal/cli/starterkit/`.
- Tests in `kernel/internal/cli` and an end-to-end test in the sdd package.
- `docs/releases/r2/DEMO.md`: how to use it on your own project.

## Explicit exclusions
- No change to the reviews connector's schemas or validation, the readiness decision, the ledger, or
  the sdd provider. No LLM or new dependency in the kernel: the reviewer is an instruction file.

## Acceptance boundary
`make check` green and one non-author code review (Law 11 budget).
