# Renew the lapsed enforce gates and compile gate-expiry into make check

**ACCEPTED under standing authorization** ([[VD-agent-standing-authorization-5ouz7q]]; owner is the
non-author acceptor, Law 9). Implements [[BR-gate-integrity-4b2e08]] obligation **O-1**: the
acceptance gate must be a trustworthy, non-rotting witness.

The R1 corp-readiness self-hosting probe (2026-11-12) found that all seven enforce-mode gate
definitions had expired **2026-10-16**, so `proofbound gates enforce` fail-closed — R1's
"gates-as-data, canary→enforce" pillar was silently dead. It rotted unseen because `make check` does
not run `gates enforce` (that needs a ledger + witnesses). Owner authorized the fix 2026-11-12.

## Allowed scope
- `gates/{index-check,make-check,kernel-check,law-citation,link,spec-numbering,invariant-table}-success.yaml`:
  renew the `expires` field from `2026-10-16` to `2027-02-16` (a ~3-month review horizon; a human
  should re-review the promoted enforce set by then). No change to gate id, mode, or rule.
- `scripts/gate-expiry.sh` (new): a blocking check that fails closed if any `gates/*.yaml` carries no
  ISO `expires` date or an expired one, so a lapsed gate definition can never again pass `make check`
  unseen (`LESSON class=silent-gate-expiry`).
- `scripts/tests/gate-expiry.test.sh` (new): its self-test (Law 3); auto-discovered by
  `make hooks-test`, so the real scan over `gates/` runs inside `make check`.

## Explicit exclusions
- No new `make` target, no `docs/gates.md` row, no census-count change (the check runs via the
  existing `hooks-test` self-test runner).
- No change to gate evaluation logic, the ledger, or kernel code.

## Acceptance boundary
`proofbound gates enforce` exits 0 again (all enforce gates PASS); `make check` green and
deterministic; the self-test proves `gate-expiry.sh` fires on an expired/dateless gate, passes a
fresh one, is boundary-inclusive, and fails closed on a missing directory. Governed commit lands with
an `Intent: CI-gate-expiry-fresh-c4e2a1` trailer and `Authorized-By: Srinivas Kamisetty`.
