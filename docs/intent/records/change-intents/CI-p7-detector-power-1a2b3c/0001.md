# P7 #2b — detector-power metric + regeneration-trust gate

**PROPOSED — awaiting owner acceptance.** This change intent requests the owner's authorization for
the governed work implementing [`BR-regeneration-trust-5f8a03`](../../requirements/BR-regeneration-trust-5f8a03/0001.md)
obligation **O-1**, the detector-power trust gate, per the accepted design spec
[P7-2b-detector-power-spec-draft1.md](../../../plans/P7-2b-detector-power-spec-draft1.md) (round-3
non-author ACCEPTABLE). The owner's §6 decisions are captured: a **shell gate** (not a kernel
package), and a **measure-first provisional `U=0`** stance. The owner remains the acceptor (Law 9);
**no governed commit lands under this intent while it is `proposed`.**

## Allowed scope
- `scripts/detector-power.sh <pkg>` + its self-test (`scripts/tests/`), computing the metric from the
  committed raw sweep + the E/R/U-classified survivor register, with the DP-1..DP-8 behaviour.
- A `docs/gates.md` advisory row (Law 4: owner + ISO expiry).
- Extend `docs/allowed-survivors.txt` with per-survivor **class (E/R/U)** + `pins` (and subsumption
  argument for R) fields, and seed `docs/verification/detector-power/<pkg>.{sweep.txt,json}`
  execution-bound records by running the deferred full-package `internal/twin` mutation sweep and
  classifying its survivors.
- Fold in the round-3 clarifications CL-1..CL-4.

## Explicit exclusions
- **No regeneration loop** (BR O-2) — that is a separate follow-on spec + change intent.
- No change to the zero-undeclared-survivors acceptance bar, the mutation harness semantics, or any
  kernel package SPEC beyond what the shell gate needs; no new provider, event kind, or feed.
- Setting the per-tier `U_BUDGET` values beyond the provisional `U=0` remains an owner decision.

## Acceptance boundary
Acceptance requires this exact scope and native self-digest; the shell gate + a fail-closed self-test
proving each DP-invariant control is load-bearing; `make check` green; a calibrated mutation sweep of
any new code with every survivor declared/classified; and an independent non-author ACCEPTABLE
verdict of the exact implementation revision (Law 9). The owner remains the final acceptor. Producing
detector-power evidence does not by itself authorize the regeneration loop (BR O-2).
