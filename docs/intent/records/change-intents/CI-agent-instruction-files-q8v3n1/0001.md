# Agent instruction files are code; agents keep off the trust configuration

**ACCEPTED by the owner 2026-11-27** ("yes make this change on the page and code", then "Targeted
fix" when asked to choose the scope). Implements [[BR-vertical-mvp-xc31gp]] O-2 (the pull-request
check reports what is not warranted) and [[BR-write-perimeter-i1xmq8]] O-5. Contract: CLI-INV-83,
CLI-INV-84, amendments to CLI-INV-33 and CLI-INV-69.

## Why
Any Markdown file was housekeeping, so `CLAUDE.md`, `AGENTS.md` and `.claude/` commands and agents
could change with no claim and no review, and the write-time perimeter let a mid-task agent edit
them, and every file under `.proofbound/` (reviewer keys, waivers, the declared tests) and `gates/`,
without being refused.

## Allowed scope

`check` and `hook commit-msg`, the trust-configuration refusal in `hook pre-tool-use`, their tests
and SPEC rows; the requirement revision and the landing page's wording (private repository).

`review seal` commit them without a claim); a reviewer key added inside the pull request still
counts (recorded as a deferral); no change to C6, warranties or the bundle; no new dependency.
