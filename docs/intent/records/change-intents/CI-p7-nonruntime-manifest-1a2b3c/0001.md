# P7-NONRUNTIME-MANIFEST-1 authorization

This accepted change intent records the owner’s explicit authorization for the bounded non-runtime
projector/build-manifest and source/toolchain-binding preparation slice.

## Allowed scope

- Define the documentary contract for a canonical projector/build manifest and its exact-revision
  source/toolchain binding.
- Implement manifest-shape validation, synthetic digest/revision tests, and evidence/review
  materials using repository or synthetic bytes only.
- Preserve existing projector and twin behavior without adding a provider, event kind, writable
  truth, or runtime behavior.

## Explicit exclusions

This intent authorizes no runtime fixture, network fetch, external artifact retrieval, binary build
or validation, PostgreSQL execution or approval, `DEF-P7-001` activation or resolution, L12/L17
result, behavior-lock acceptance, clean-clone proof, or runtime verdict. It also authorizes no case-
manifest parser, lock evaluator, regeneration implementation, provider, feed, schema event, or new
writable projection unless separately authorized.

## Acceptance boundary

Acceptance requires exact-revision binding, fail-closed shape and digest tests, independent
non-author review of the exact implementation commit and review packet, and the listed repository
checks. Incomplete evidence remains `UNVERIFIED` or `PENDING`; this intent does not claim runtime
or binary acceptance.
