# A killed proofbound no longer leaves its database in the way

**ACCEPTED by the owner 2026-11-27** ("lets do all 3", naming the deferral). Implements
[[BR-vertical-mvp-xc31gp]] O-1: a stranger reaches a first PASS without help, and a run killed mid-way
(SIGKILL, or SIGPIPE from `| head`) must not leave Proofbound unusable until someone runs `pg_ctl` by
hand. Resolves `DEF-ORPHAN-EMBEDDED-PG-001`. Contract: store SPEC INV-28 (amended 2026-11-27), whose
first half the SPEC promised and the store never implemented.

## Allowed scope
`kernel/internal/store` (`Open` stops an orphan of its own data directory before starting; a new
`orphan.go` and `orphan_test.go`), the store SPEC's INV-28 amendment and row, and docs.

## Explicit exclusions
No new dependency, no exported API change, no change to the lock. A server for another data directory
is never stopped. The first-start crash window (a run killed between initdb and the database's creation
leaves a cluster without its database) is a separate pre-existing defect, not fixed here.

## Acceptance boundary
`make check` green; a test that kills a real child process mid-run and fails without the fix, with
calibration controls (no stop call, `sameDir` always true, marker identity only: each must fail); the
same kill reproduced on the real binary recovering on the next run; one non-author code review.
