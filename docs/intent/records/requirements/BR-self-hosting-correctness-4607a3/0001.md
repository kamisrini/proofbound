# The product runs correctly on Proofbound's own record

Authorized by [[BD-self-hosting-correctness-11bcf2]]. Obligation **O-1**: the Release-1 product
surface must succeed on this repo's own real ledger, and the commit projection must accept every
validly-formed decision citation — both the random-6-char-token and the `YYYY-MM-DD` phase-decision
suffix conventions the `/proofbound-decide` skill mints — while still failing closed on malformed
citations (P-INV-7). The regression guard must run under `make check`, not only under
`-tags integration`.

This requirement is `proposed`; it goes `active` after a non-author requirement review
(`scripts/p6-task5-review.sh`). Its first implementation is [[CI-fix-vd-citation-9958b1]]. The owner
remains the acceptor (Law 9).
