# Release-line decisions are governed and intent-bound

Authorized by [[BD-release-line-governance-a01de6]]. Obligation **O-1** is the release-governance
obligation: drawing or moving Proofbound's own release line is governed work — recorded in a VD,
committed under an explicit `Intent:` trailer that binds an accepted change intent, regenerating the
governed `docs/decisions/INDEX.md` under intent rather than HEAD-only, and kept consistent with the
maintained scope split in [`RELEASE-PLAN.md`](../../../plans/RELEASE-PLAN.md).

This requirement is `proposed`; it goes `active` only after a non-author requirement review
(`scripts/p6-task5-review.sh`). A change intent may target a `proposed` requirement's obligation
meanwhile. Its first implementation is [[CI-release-line-4069b0]], which records the first release
line ([[VD-release-line-kwdh4v]] — not a wiki file; the authority is
`docs/decisions/VD-release-line-kwdh4v.md`). The owner remains the acceptor (Law 9).
