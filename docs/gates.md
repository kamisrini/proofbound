Every check in this repo is listed here with its tier and enforcement point. **Law 4: nothing advisory without an owner and an ISO expiry date** — a dateless ADVISORY row fails `make link-lint`; an expired one either graduated to blocking or gets deleted (log the deletion in a journal entry). **This table is also the single home of the meta-tax budget** (Law 2).

Supersedes the `make wrap-verify` assertion in practice, which by design ran only at `/vera-wrap` and has three recorded bypasses. **Why commits not minutes:** minutes punish a long careful think and forgive a burst of ten commits, which is backwards — commits measure how far the repo has moved from what the note says. **Known limit:** it checks the note was REWRITTEN, never that the narrative is accurate — the same accompaniment-not-truth limit `figure-provenance` and `skip-lint` carry. `make state` prints the derived half | `scripts/tests/state-freshness.test.sh` (11 cases; case 5/5b pin the being-rewritten-now exemption, case 6 blocks an unrelated dirty file from laundering staleness, case 2 pins the boundary as inclusive) | — |
| Mutation sweep — every survivor is declared | BLOCKING at PACKAGE ACCEPTANCE (not in `make check`) | `scripts/mutants.sh <pkg>` over `tools/mutants` (stdlib-only, Law 8). It sits in the same slot as adversarial review. **Calibration is mandatory and has THREE controls:** neutral (a comment — must survive), compile (undefined symbol — must be invalid), and LETHAL (an injected always-failing test — must be killed). The third is not redundant: if `go test` were silently not running, the first two would both still pass and the harness would declare itself sound having never run a test. **`invalid` is a first-class outcome** — an uncompilable mutant proves nothing and is never counted as killed, because a false kill claims coverage that is absent. **Known limits:** shipped source only, never `_test.go`; a fixed small operator set, so no survivors means the operators found nothing, NOT that the package is proven; and it says nothing about whether a test asserts the RIGHT thing — round 2 found mutation-killing tests that still could not discriminate the property they were named for | `scripts/tests/mutants.test.sh` | — |

## Known accepted bypasses (named, not silent)

- **Bash-channel writes to future `@generated` files:** the Write/Edit hook cannot see shell redirections. Mitigated for the known artifact (INDEX.md guard in block-secrets.sh) and backstopped by `make index-check` freshness. Any NEW generated artifact must add both a guard pattern and a freshness check — reviewer rejects otherwise.
- **Binary derived artifacts:** none exist today. Any future binary derivation is exempt from the `@generated` marker gate and MUST instead declare its regeneration command in the file that references it.
- **Ledger migration SQL (`kernel/internal/store/migrations/*.sql`):** generate-once / append-only by discipline, not by hook. A landed migration is never hand-edited — goose has already applied it, so an edit rewrites history silently in every database that ran the old text. The ledger also carries no `-- +goose Down`: an append-only ledger has no reverse gear, and a correction is a NEW migration. Backstopped by `kernel/internal/store/surface_test.go::TestNoMutatingLedgerSQL`, running under `make check`. **Honest reach, re-verified at round 9 — this clause has been wrong twice, in both directions:** the scan reads EVERY non-test `.go` file in the package (in or out of the current build — a build-excluded file's SQL still ships in the package) plus every `.sql` file; it folds `+` concatenations of string literals and package-level consts, resolving consts recursively. It does NOT see: `strings.Builder`, `fmt.Sprintf`, `strings.Join`, values from function calls, package-level `var` operands, or **function-LOCAL consts** (the resolver indexes package-level names only — round-9 MED-3, proven with a shipped file). Editing a landed migration is a reviewer rejection. |

## Rules for this file

- Adding any check anywhere (hook, Makefile, CI) without a row here fails `/vera-review`.
- Expiry mechanism: `scripts/link-lint.sh` (inline — there is no separate gate-expiry script).
