Coding agents · Agent surface

Agents read the same record, typed, with the next command.

Every workspace a person sees is also JSON at the same address. An agent never parses prose: it gets states, commit ids and commands, so a person and an agent act on one truth. Agents read; people act.

How an agent connects

While proofbound ui runs, it writes .proofbound/ui.json (readable only by you) with its address and token. An agent of the same user reads it and sends the token:

u=$(jq -r .url .proofbound/ui.json); t=$(jq -r .token .proofbound/ui.json)
curl -s -H "Authorization: Bearer $t" "${u}agent/next"
