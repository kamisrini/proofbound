Limitations

  
    
    
  • Whether every line of a claimed commit stays inside its spec is checked by the reviewer reading the change, not line by line here.
    • 
    
  • Actions an agent took outside the repository (commands, secrets, network calls, deployments) are not visible to this audit.
    • 
    
  • Outcomes are signed statements by the person who recorded them; "risk accepted" and "reverted" are not verified against the code.
    • 
    
  • Author and agent names are self-declared in git unless the commit is signed by a declared key; agent sessions are visible only on the machine where they ran.
    • 
    
  • Signed outcomes, countersignatures and review files are checked again in your browser; git commit signatures are checked by proofbound only.
    •
